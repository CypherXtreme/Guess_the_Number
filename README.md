# Guess the Number

A browser game built with plain HTML, CSS and JavaScript. The computer picks a secret number from 1 to 100 and you guess it, with "higher" or "lower" hints after every try. Guess it in fewer than 10 attempts and you're a genius.

## Features

- Number line that shades out the ranges you've ruled out
- Attempt counter and guess history
- Enter key support, input validation, play again button
- Responsive, keyboard accessible, light and dark mode

## Run it

Open `index.html` in any browser. No build step or dependencies.

## Put it online with GitHub Pages

1. Push these files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then save.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.

## Files

- `index.html` – the whole game (HTML, CSS and JavaScript in one file)
